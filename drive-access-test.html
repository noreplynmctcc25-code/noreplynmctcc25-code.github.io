Drive access test

Checks whether a department head's account can read a file a teacher shares, using only the narrow drive.file permission the Class Record app already uses. Nothing here touches your real class records.

Setup

Host this page on the same site as the app so the Client ID's authorised JavaScript origin already matches. The Client ID is shared with the app if it is stored in the same browser.
